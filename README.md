# IPTV Perso – Apple TV (tvOS)

Branche séparée de l'appli Fire TV. Chaque push compile l'appli sur un Mac GitHub (onglet **Actions**).

Le projet Xcode prêt à ouvrir se télécharge dans le dernier run réussi : artefact **IPTVPerso-Xcode**.
Ouvre `IPTVPerso.xcodeproj`, choisis ta Team (Apple ID gratuit) dans Signing & Capabilities, puis ⌘R.
